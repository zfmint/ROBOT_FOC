# 电流环


## 核心要点
解决的问题：获取电机实际需要多少电压，判断电机实际电流是否符合预期\
获取的是电流量,经过PI控制算法输出电压量\
PID模块已经单独完成，可复用\

> 重点


## 需求规格
### 功能描述
由FOC模块输入经过Park变换后的Id，Iq作为采样值\
接收当前目标值Id，Iq\
在内部对dq轴电流分别进行PI计算
逆Park变换转换为Uα，Uβ
电压限幅
输出给SVPWM计算占空比

### 输入输出
输入： dq轴目标电流、反馈电流、母线电压（用于限幅）、电角度（用于逆Park变换）\
输出： dq轴输出电压、限幅结果、状态\
每个电流独立PI算法，内部PI参数与误差值独立,内部需要保留状态
