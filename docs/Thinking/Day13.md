# SVPWM（空间矢量脉宽调制）


## 核心要点
3个桥臂，每个桥臂有2个开关状态，共有8个状态\
8个状态包括6种有效电压矢量与2种零电压矢量（全0，全1），形成了6个扇区，每60°为一个扇区。



## 坑点 & 踩坑记录
电压矢量的扇区判断\
第一扇区(Uα > 0,Uβ > 0)：Uβ < √3*Uα\
第二扇区：Uβ > √3*Uα\
第三扇区(Uα < 0,Uβ > 0)：Uβ < √3*|Uα|\
第四扇区(Uα < 0,Uβ < 0)：|Uβ| < √3*|Uα|\
第五扇区(Uβ < 0)：|Uβ| > √3*|Uα|\
第六扇区(Uα > 0,Uβ < 0)：|Uβ| < √3*Uα\

以PWM周期中心为对称轴，开关状态按照对称顺序排列
> 重点
1. 接收限幅后的 αβ 电压矢量
2. 判断当前扇区
3. 换算至第一扇区
4. 计算T1、T2、T0。这三个值对应各扇区映射到第一扇区时的时间状态，计算出开启时间后换算到每个状态是各个mos管的开启时间。
5. 计算两个有效矢量的作用时间
6. 计算三相调制结果

## 需求规格
### 功能描述
根据当前电压分量计算mos管占空比

### 输入输出
输入 park逆变换后电压分量
输出 三项占空比

### 功能流程
对输入电压量进行限幅
判断限幅后的分量所在扇区
将所在扇区换算到第一扇区
计算分量在第一扇区的T1T2T0
返回分量所在扇区
计算占空比
