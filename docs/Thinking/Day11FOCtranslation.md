# FOC Translation


## 核心要点
电机三相电流Ia,Ib,Ic。三相相加为0。\
经过Clark变换为αβ正交坐标系，固定在定子上。\
经过Park变换，将αβ正交坐标系中的向量投影到旋转的dq坐标系上。

dq轴坐标系随着转子旋转。
Id = Iα*cosθ+Iβ*sinθ
Iq = -Iα*sinθ+Iβ*cosθ


## 坑点 & 踩坑记录
需要明确的设计原则：\
clarke与park都是独立的数学运算模块\
电角度获取与处理和编码器的测速职责区分，现在还没有实现电角度的编码器读取功能\
角度统一使用common中的定义\
接口需要保证数据的正确性


> 重点
1. Clarke采用幅值不变形式
2. Clarke接收两相电流，依赖三相平衡假设
3. α 轴与 a 相轴重合，β 轴逆时针超前 90°。
4. d 轴相对 α 轴旋转 θ，q 轴相对 d 轴逆时针超前 90°。
5. 所有角度统一使用弧度制。
6. 变换模块检查数值有效性，上游负责物理范围校验。
7. 计算失败时保留旧输出，并返回错误状态。
8. 变换模块不负责决定电机停机或保护策略。


在既定的 Transform 架构下组织四种变换能力。
Clarke 采用幅值不变形式，输入两相电流电压，电压可以传入两相，算出第三相
Park、逆 Park 使用统一的电角度约定，角度单位为弧度。
电流与电压使用不同的结构体，通过函数重载区分公共接口。
内部复用数学计算逻辑，辅助函数不对外暴露。
统一错误状态，至少包含 OK 和 INVALID_INPUT
失败时输出不变；调用方必须检查返回状态。
通过类型名称和注释表达接口语义与行为契约
